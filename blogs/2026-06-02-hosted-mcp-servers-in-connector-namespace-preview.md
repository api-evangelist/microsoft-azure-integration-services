Azure now supports hosting Model Context Protocol (MCP) servers within Connector Namespaces in preview, enabling AI agents to securely access enterprise tools and connectors via the MCP standard. The feature solves production connectivity limitations by providing managed, enterprise-grade MCP server hosting.
